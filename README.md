# HTML with Node.js & Express

A simple web application demonstrating how to serve static HTML pages using Node.js and Express.js.

## Tech Stack
- Node.js
- Express.js
- HTML5
- CSS3
- JavaScript

## Project Structure

```text
convert-html-to-nodejs/
├── public/
│   └── index.html
├── server.js
├── package.json
└── package-lock.json
```

## Getting Started

**1. Install dependencies**

```bash
npm install
```

**2. Start the server**

```bash
node server.js
```

**3. Open in your browser**

Visit [http://localhost:3000](http://localhost:3000).

## Features
- Serves static files using Express middleware.
- Responsive webpage with custom CSS styling.
- Interactive button powered by JavaScript.

## How It Works

Node.js runs the server, Express serves files from the `public` directory, and the browser renders the HTML, CSS, and JavaScript.
